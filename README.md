# Скрипт для пробуждения ПК по WakeOmLan снаружи локальной сети по http запросу

Python+Flask

В .env файле в той же папки ввести свою конфигурацию, пробросить порт и готово
```
# MAC-адрес компьютера, который нужно включить
TARGET_MAC=10:2A:34:5B:22:44

# Broadcast адрес локальной сети
DEST_IP=255.255.255.255

# UDP порт Wake-on-LAN
DEST_PORT=9

# Токен
WOL_SECRET_TOKEN=123456789

# Порт Flask API
SERVER_PORT=8080
```
Токен для аутентификации, его указываем при отправке запроса
